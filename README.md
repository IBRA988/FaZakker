## ✨ أبرز التحديثات والمميزات

### 🕌 1. مواقيت الصلاة والأذان المباشر (`prayers.html` & `index.html`)
- **تسمية هادفة للملفات**: تم تنظيم ملف الصفحة الرئيسية والصلوات تحت اسم `prayers.html` و `index.html`.
- **دعم مدينة الهفوف والأحساء بشكل افتراضي**: إضافة مدينة الهفوف (الأحساء) والمبرز وكافة مدن المملكة العربية السعودية والعواصم العربية إلى القائمة.
- **التحديد الجغرافي التلقائي (GPS)**: إمكانية تحديد موقعك بضغطة زرواحدة وجلب المواقيت بدقة.
- **عدّاد تنازلي سليم ومباشر للصلاة القادمة**: حساب الساعات والدقائق والثواني المتبقية مع إبراز كارت الصلاة القادمة.
- **إشعارات الأذان والتنبيه الصوتي**: إشعارات المتصفح المباشرة وخيار الاستماع للأذان.

### 🌗 2. التبديل الفوري بين الوضع الداكن والفاتح (Dark / Light Mode)
- **مظهر دافئ وفخم في الوضعين**: إمكانية التبديل بين الوضع الداكن الملكي والوضع الفاتح الأنيق بضغطة زر واحدة (☀️ / 🌙) مع حفظ تفضيل المستخدم تلقائيًا.

### 📐 3. واجهة مرنة وتجاوب سلس (Flexible UX & Collapsible Sidebar)
- **طَي وتوسيع القائمة الجانبية (Collapsible Sidebar)**: زر طَي القائمة لتكبير مساحة القراءة والعرض على الشاشات المختلفة.
- **تجاوب شامل للأجهزة المحمولة**: شريط تنقل سفلي مرن يظهر تلقائيًا على الشاشات الصغيرة.

### 📖 4. القرآن الكريم والمصحف الشريف (`quran.html`)
- **عرض صفحات المصحف بالرسم العثماني (SVG)**: تصفح الـ 604 صفحة بدقة متجهة عالية.
- **التلاوات الصوتية لكبار القراء**: (الشيخ مشاري العفاسي، عبد الباسط عبد الصمد، محمود خليل الحصري، ماهر المعيقلي، وسعد الغامدي).
- **حفظ العلامة المرجعية وأدوات التكبير/التصغير والأسهم**.

### 📿 5. الأذكار والمسبحة الإلكترونية (`azkar.html`)
- **أذكار حصن المسلم مع عداد تفاعلي وبحث فوري ومسبحة رقمية دائرية**.

## 📁 هيكل المشروع (Project Structure)

```text
FaZakker/
├── prayers.html                # صفحة مواقيت الصلاة الأساسية والعد التنازلي
├── index.html                  # البوابة الرئيسية لـ مواقيت الصلاة
├── quran.html                  # صفحة القرآن الكريم والتلاوات الصوتية
├── azkar.html                  # صفحة الأذكار والمسبحة الإلكترونية
├── package.json                # بيانات المشروع والاعتماديات والسكربتات
├── README.md                   # التوثيق الشامل للمشروع
├── assets/
│   ├── css/
│   │   ├── main.css            # النظام التصميمي والوضع الداكن/الفاتح والشريط الجانبي
│   │   ├── prayers.css         # أنماط بطاقات المواقيت والعداد التنازلي
│   │   ├── quran.css           # أنماط قارئ المصحف الـ SVG ومحرك الصوت
│   │   └── azkar.css           # أنماط بطاقات الأذكار والمسبحة الرقمية
│   ├── js/
│   │   ├── common.js           # محرك الوضع الداكن/الفاتح والقائمة والأصوات
│   │   ├── prayers.js          # منطق المواقيت وتحديد الموقع ومدينة الهفوف والعداد
│   │   ├── quran.js            # منطق جلب المصحف والتلاوات والعلامات
│   │   └── azkar.js            # منطق العدادات التفاعلية والمسبحة الرقمية
│   └── images/
│       └── favicon/            # أيقونات التطبيق والشعار الرسمية
└── docs/
    └── learning-notes.js       # ملاحظات تعليمية جانبية
```
