## ✨ أبرز مميزات التطبيق

### 🕌 1. مواقيت الصلاة والأذان المباشر (`index.html`)
- **حساب دقيق للمواقيت**: جلب مواقيت الصلوات الخمس والشروق اعتمادًا على أحدث طرق الحساب الفلكية (Aladhan API).
- **التحديد الجغرافي التلقائي (GPS)**: إمكانية تحديد موقع المستخدم بضغطة زرواحدة، بالإضافة لإمكانية الاختيار من قائمة المدن العربية والعالمية.
- **عدّاد تنازلي مباشر للصلاة القادمة**: عرض الساعات والدقائق والثواني المتبقية مع إبراز كارت الصلاة القادمة بتصميم مضيء.
- **التقويم الهجري والتوقيت المحلي**: عرض اسم اليوم والتاريخ الهجري والتقويم الميلادي بصيغة 12 ساعة مع مؤشرات (صباحًا/مساءً).
- **إشعارات الأذان والتنبيه الصوتي**: تفعيل إشعارات المتصفح المباشرة وإمكانية الاستماع لإنذار صوت الأذان.

### 📖 2. القرآن الكريم والمصحف الشريف (`quran.html`)
- **عرض صفحات المصحف بالرسم العثماني (SVG)**: تصفح صفحات المصحف الـ 604 بدقة متجهة عالية تضمن وضوح النصوص على مختلف الشاشات.
- **التلاوات الصوتية لكبار القراء**: الاستماع لتلاوة السور بصوت قراء العالم الإسلامي (مثل: الشيخ مشاري العفاسي، عبد الباسط عبد الصمد، محمود خليل الحصري، ماهر المعيقلي، وسعد الغامدي).
- **حفظ العلامة المرجعية (Bookmarking)**: حفظ صفحة التوقف التلقائي واستعراض رباط العلامة المرجعية الذهبي.
- **التحكم بالتقريب والتنقل**: أدوات تكبير وتصغير الصفحة (Zoom In / Zoom Out) بالإضافة لإمكانية التنقل باستخدام أسهم اللوحة (`←` و `→`).

### 📿 3. الأذكار والمسبحة الإلكترونية (`azkar.html`)
- **أذكار حصن المسلم**: أذكار الصباح، أذكار المساء، أذكار بعد الصلاة، أذكار النوم، أذكار الاستيقاظ، وغيرها.
- **عداد تفاعلي لكل ذكر**: الضغط على كارت الذكر ينقص العداد تدريجيًا مع إظهار شارة الاكتفاء وتغيير لون الكارت عند إتمام التكرار المطلوب.
- **البحث الفوري في الأذكار**: حقل بحث مباشر لتصفية النصوص والأدعية حسب الكلمات المفتاحية.
- **المسبحة الإلكترونية الرقمية**: شاشة تسبيح دائرية تفاعلية تتيح اختيار صيغ التسبيح وتحديد الهدف (33 / 100 / مفتوح) مع مؤثرات صوتية واهتزازية هاتفية.

## 🚀 كيفية التشغيل والملاوذة المحلية (Getting Started)

التطبيق يعتمد على تقنيات الويب القياسية (HTML5 / Vanilla CSS / Modern JavaScript ES6+) دون الحاجة لخطوات تجميع معقدة:

### 1. تشغيل مباشر في المتصفح
قم بفتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Edge, Safari).

### 2. التشغيل عبر خادم محلي (Local Dev Server)
يمكنك استخدام `serve` لفتح المشروع على خادم محلي:
```bash
# تثبيت الاعتماديات (إن وجدت)
npm install

# تشغيل الخادم المحلي
npm start
```
ثم افتح الرابط المحلي الموضح في الشاشة: `http://localhost:3000`

## 🛠️ التقنيات والمكتبات المستخدمة (Technologies Used)

- **HTML5 & Semantic Elements**: بناء هيكل متجاوب وإتاحة الوصول (Accessibility).
- **Vanilla CSS3 & CSS Variables**: تصميم نظام ألوان زجاجي (Glassmorphic Emerald & Gold Palette) متكامل ومتجاوب عبر Media Queries.
- **Vanilla JavaScript (ES6+)**: برمجة وحدات كود نظيفة (Modular JS architecture) وإدارة الحالة بنظام `localStorage`.
- **FontAwesome 6.5**: مكتبة الأيقونات الفاخرة.
- **Axios JS**: إجراء طلبات الشبكة (HTTP Requests) لجلب البيانات المباشرة.
- **Aladhan API & Mp3Quran API**: مصادر بيانات المواقيت وصفحات المصحف والتلاوات الصوتية.
